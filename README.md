# Saranggola Royale 0.3.0 · Laban ng Bayan

[Download the signed Android APK](SaranggolaRoyale-0.3.0.apk)

Play offline as one of 12 heroes in Solo or six Duos. Glide off the saranggola, find weapons and gear, and survive the Bagyo. Duos can revive a downed partner or return their Kaluluwa at a Parol Beacon before Phase 3. The last hero or duo standing wins.

The Android package supports arm64 devices with Android 7.0 or newer. It uses the same package name and signing certificate as the Hapag v0.2.0 APK. Open the downloaded APK to install the update.

APK signature, alignment, packaged game assets, and desktop smoke checks passed. Physical Android install and device performance remain unverified. See [SHA256SUMS](SHA256SUMS) to check the download.
