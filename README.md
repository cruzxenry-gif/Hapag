## This update

- Meal logging, Foods and saved recipes extend the charcoal/soft-white/sage style.
- Search, filters, creation/label actions and results scroll together, with keyboard clearance. Clear search preserves the selected Saved foods/Recipes context.
- Full-width portion amounts and wrapping household-unit/gram choices. Entered cost appears beside review nutrition; optional reference photos have their own section.
- Clear recipe yield, ingredient sources and batch/serving costs; a full-width serving action.
- Explicit whole-row Skip targets for unmatched phrases, 52dp typed-review actions, and a scrollable recipe-save dialog body.

Existing offline OCR, recipe/meal snapshots, exact costs, backup/restore, Undo and saved theme remain. The existing bounded glass/fallback and Android 15 button-navigation appearance exception remain; no network permission or new database migration is added.

See [validation and limits](VALIDATION.md) and [checksums](SHA256SUMS.txt). This remains a development build. Native evidence uses software emulators; physical-device performance, full TalkBack and camera/provider certification are not claimed.
